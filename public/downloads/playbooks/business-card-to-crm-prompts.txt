Business card to CRM: 10 AI prompts for event follow-up
Bizgenix AI playbook · checked 2026-11-28 · https://bizgenix.ai/playbooks/business-card-to-crm-prompts

What this set does
After a trade show or business event you come back with a stack of visiting cards. These ten prompts turn photos of those cards into a clean contact sheet, a follow-up message for each person and a priority list, using any AI assistant that reads images (ChatGPT, Claude or Gemini).

Use them in order: extract, clean, score, then write the follow-ups. Check the extracted phone numbers and emails against the card before you send anything.



1. Business Card Data Extraction
Analyze this business card image.
Extract and return the following fields in JSON format:
{
"full_name":"",
"job_title":"",
"company":"",
"email":"",
"phone":"",
"website":"",
"linkedin":"",
"address":""
}
Rules:
- Return only valid JSON.
- If information is missing use null.
- Fix OCR mistakes when obvious.
- Maintain proper capitalization.
- Verify email formatting.


2. Google Sheets Formatter

Convert extracted business card data into spreadsheet-ready rows.

A sensible routine after an event
1. Photograph every card the same evening.
2. Run prompt 1 on each photo, then prompt 2 to get one sheet.
3. Run prompt 8 to pick the ten people worth a personal message.
4. Send those ten a message you have read and corrected yourself. Use the bulk prompt only for the rest.
